LT Butai Privacy Policy

Last updated: 23 September 2026

LT Butai is a private application used to manage apartment invoices and related workflows.

Google account data

LT Butai uses Google OAuth to access Gmail only for functionality requested by the user.

The application may use Gmail access to:

  • Find emails matching configured invoice sender and subject criteria.
  • Read those emails and download PDF invoice attachments.
  • Send completed invoice documents when explicitly requested by the user.

Data usage

Google user data is used only to provide the invoice processing functionality described above. It is not sold, used for advertising, or shared with third parties for unrelated purposes.

Data storage

OAuth credentials, application state and downloaded invoice documents are stored privately by the application owner and are not made publicly available through this website.

Access and revocation

Google account access can be revoked at any time through the user's Google Account security settings.
